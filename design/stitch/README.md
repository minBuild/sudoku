### 구현 시 주의 (생성물과 실제 앱의 차이)
- Stitch 가 임의로 덧붙인 요소는 구현하지 않는다: 하단 내비게이션 바(게임/일일 챌린지/통계/설정), 일시정지 버튼, 잔여 개수 라벨, PRO 뱃지, 홈의 "계속 플레이"·진행률 바·태그라인 문구, 설정의 "Sudoku Studio" 문구.
- `game`/`game-menu` 의 메뉴 항목은 정확히 3개(다시 시작·즉시 체크·효과음)다.
- 메모 하이라이트는 CustomPaint 로 직접 그린다 (HTML 의 pill 은 참고용).
- `app-icon` 시트는 SVG 이미지형 화면이다. 실제 아이콘은 코드로 렌더한다(`BrandMarkPainter`).
- 실제 기능과 문구는 `lib/l10n/app_*.arb` 를 따른다. 가격 숫자는 스토어 `ProductDetails.price` 만 쓴다.
